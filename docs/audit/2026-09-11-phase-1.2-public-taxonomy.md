# Phase 1.2 — Public Taxonomy Archives

Status: **Completed locally**

## Scope

Taxonomy terms were manageable in the Admin Panel but did not yet have a real public destination. This phase connects a term to a public archive containing only published, site-scoped content assigned to that term.

## Delivered

- Added public routes shaped as '/{taxonomy}/{termSlug}' alongside the existing '/page/{slug}' and '/post/{slug}' routes.
- Added exact site, taxonomy, locale, and slug lookup for terms.
- Added term-aware content queries in both Pinoox and in-memory repositories.
- Added a responsive RTL archive renderer with escaped term metadata, canonical URL, related content cards, and an explicit empty state.
- Kept unknown, private, malformed, and unpublished data out of the public response.
- Registered the capability in the package service/feature metadata.

## Validation

- PHP syntax checks: passed for changed files.
- CMS PHP runtime suite: '53 passed, 0 failed'.
- Regression coverage verifies published-only term filtering, escaped public rendering, canonical output, and route ordering/filter constraints.
- Previous Admin suite/build remains valid: '163 passed, 0 failed'; verified production dist contains the taxonomy Admin page and '62' assets.
- 'git diff --check': passed.

## Remaining risk

Live Pinoox database and browser verification were not executed in this phase. The next phase should validate the mounted route with real terms and content, then add term links to public content cards and a browser smoke path.
