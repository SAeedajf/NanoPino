# NanoPino

NanoPino is the native Pinoox CMS and extension platform package (`com_pinoox_cms`).

Current release candidate: **0.23.72 / code 2372**.

Installable artifact: [NanoPino 0.23.72 RC1](https://github.com/SAeedajf/NanoPino/releases/tag/v0.23.72-rc1).
Download the `.pinx` asset and its adjacent `.sha256` file from that release,
then install it through the native Pinoox PINX installer.

The source-first release workflow, verification gates, target-environment requirements,
and known Stable blockers are documented in:

- [`docs/index.md`](docs/index.md)
- [`docs/deployment/release-gate.md`](docs/deployment/release-gate.md)
- [`docs/UPDATE-WORKFLOW.md`](docs/UPDATE-WORKFLOW.md)

The candidate is locally signed and archive-verified, but is not declared Stable until target trust-chain, target Pinoox/DB,
authenticated browser/WCAG, recovery, security, performance, and deployment evidence
are complete.
