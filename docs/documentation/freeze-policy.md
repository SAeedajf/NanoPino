# Documentation Freeze Policy

Documentation reaches freeze only when required files exist, machine contracts are current, prose does not claim unimplemented APIs, breaking changes include migration documentation, examples are tested or clearly illustrative, and target-environment claims have captured evidence.

Machine-readable schemas/API contracts win over prose. Historical phase reports are not authoritative for current behavior.

The current documentation state remains **candidate** until release blockers in the documentation manifest are resolved or explicitly deferred.
