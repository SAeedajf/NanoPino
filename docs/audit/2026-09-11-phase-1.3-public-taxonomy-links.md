# Phase 1.3 — Public Content Taxonomy Links

## Status

Completed locally. Live deployment and browser verification were not executed in this phase.

## Problem

Published content pages showed their body and canonical URL, but visitors had no direct path from a page to the public taxonomy archive for its assigned categories or tags.

## Implementation

- PublicContentController::show() now resolves the record's taxonomy assignments in one batched term lookup.
- Only public taxonomy definitions are rendered.
- Links are restricted to the same site, taxonomy and locale as the published content record.
- PublicPageRenderer renders an accessible, responsive taxonomy navigation below the page metadata.
- Link labels and URLs are escaped before output.
- Existing public URL and published-only behavior remains unchanged.

## Validation

- PHP regression coverage checks taxonomy link rendering, accessibility labeling and output escaping.
- Node static contract coverage checks the public filtering guards and renderer contract.
- git diff --check and PHP syntax validation are required release checks.
- Live Pinoox database/browser validation: Not executed.

## Remaining risk

The public controller still uses the fixed site and locale selected by the current Pinoox app contract. A future multi-site/multi-locale phase should derive these from the request context rather than hard-coded defaults.
